# Engineering Log

A dated record of what I tried, what broke, and what I changed.
**Write each entry yourself, the day it happens.** This file is where interview stories come from.

Template:
```
## YYYY-MM-DD - short title
**Tried:**
**What happened / what broke:**
**Changed:**
**Result (numbers if possible):**
```
